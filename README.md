# スタバ注文ノート (Coffee Order Notes)

スタバのサイズ・カスタマイズ・注文フレーズ・地域限定情報をまとめた非公式サイト。GitHub Pagesで公開。

## 公開URL

GitHub Pages有効化後: `https://yoshi4486.github.io/sutaba-order-notes/`

## 広告 (Google AdSense)

`index.html` の `<head>` 内にAdSenseスクリプトのコメントアウト箇所があります。審査通過後、`ca-pub-XXXXXXXXXXXXXXXX` を発行された publisher ID に置き換え、コメントを外してください。

広告枠の場所(`.ad-slot`)は3箇所用意済みです:
- `#ad-slot-top` — ヘッダー直下
- `#ad-slot-mid` — カスタマイズ一覧の後
- `#ad-slot-bottom` — フッター直上

各枠の中に、AdSenseの管理画面からコピーする `<ins class="adsbygoogle">` タグを追加してください。

サイト運営者は `ads.txt` の設置も必要です(AdSense申請時に案内される内容をリポジトリ直下に配置)。
